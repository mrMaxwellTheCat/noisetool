# Changelog

## 1.0.0 (2026-05-21)

### Added
- Interactive wizard mode with quick and custom setup
- 6 noise types: white, pink, brown, blue, violet, grey
- CLI with 50+ options organized in help groups
- ITU-R BS.1770-4 LUFS loudness measurement and normalization
- Audio effects: DC blocker, fade in/out, reverse, phase invert
- Filters: lowpass, highpass, bandpass (FFT-based)
- ADSR envelope generator
- Stereo width, pan, amplitude modulation (tremolo)
- Bitcrushing and dithering
- Dynamic range compressor
- Multi-format output: WAV, FLAC, AIFF, OGG, RAW
- Parallel multi-threaded generation
- Continuous generation mode
- Seamless looping noise
- Batch config from JSON/YAML files
- Shell completion (bash, zsh, fish)
- Audio analysis: stats, waveform, spectrum, EQ viz
- JSON and CSV export of audio statistics
- File info command (--info)
- Performance benchmark mode
- Preset configurations (streaming, broadcast, podcast)
- Multi-seed batch generation
- Custom filename patterns
- Silent mode and progress style options
- Docker support
- 190 tests with CI/CD pipeline
